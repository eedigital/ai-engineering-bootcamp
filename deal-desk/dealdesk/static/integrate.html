Plugging Deal Desk into One Click

Deal Desk is built to sit inside One Click's existing journey rather than beside it. One Click has no public API, so Deal Desk offers the four standard ways a platform adds a tool. Each works on its own; together they cover the Trade Action Plan, the AI assistant and the SME Trade Catalogue.

Where in One ClickHow Deal Desk connects
Trade Action Plan: shipping and getting paid stepsEmbed (2) or launch link (1), with the deal pack saved back to the plan
AI assistantTool definitions (3), so it can answer "which Incoterm?" from rules, not guesses
SME Trade CatalogueLaunch link (1) as a catalogue entry
ChambersCertificate-of-origin handoff in every deal pack

1. Launch link

Open Deal Desk with the deal already filled in. Any field can be left out. Countries can be names or two-letter codes.

/?product=Olive%20oil&origin=ES&destination=Germany&value=48000&currency=EUR&mode=road&buyer=Feinkost%20GmbH

mode is one of sea_container, sea_bulk, air, road, rail, multimodal.

2. Embed

One line places Deal Desk inside a One Click page. It resizes itself and hands the finished deal pack back to the page.

<div id="deal-desk"></div>
<script src="https://YOUR-DEAL-DESK-HOST/embed.js"
        data-target="#deal-desk" data-destination="Germany" data-currency="EUR"></script>
<script>
  document.querySelector('#deal-desk').addEventListener('dealdesk:complete', (e) => {
    // e.detail is the deal pack: deal, Incoterms rule, payment, documents, terms sheet
    saveToTradeActionPlan(e.detail);
  });
  // Later, e.g. when the SME picks a market in the Trade Navigator:
  // DealDesk.prefill({ destination: 'Kenya', mode: 'air' });
</script>

3. AI assistant tools

GET /api/tools returns function definitions in the common tool-calling format. One Click's assistant can call deal_desk_plan to answer delivery and payment questions from fixed rules, and deal_desk_read to check a buyer's message for risky terms.

4. API

POST /api/plan takes a deal and returns the full plan instantly. It uses rules only, no AI, so the same deal always gets the same advice. POST /api/read reads a buyer's text or PDF. Full reference: /docs.

For production

  • Accounts: pass One Click's signed-in user through a short-lived signed token so deal packs save to their account.
  • Allowed sites: set ALLOWED_ORIGINS to One Click's domains.
  • Languages: One Click runs in English, Arabic, French and Spanish; Deal Desk's text is kept in one place to translate.
  • Content: link each rule to ICC's official Incoterms® 2020 text and model contracts, and route expert reviews to chambers.
